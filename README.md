# North Loom storefront preview

Responsive retail concept inspired by SHEIN's search, category navigation and product grids, retaining the North Loom identity. Products, AUD prices, sizes and photography are illustrative. No orders or payments are processed.

Open index.html or serve this folder with a static HTTP server. No installation or build is needed. app.js contains the sample catalog and implements search, filters, sorting, saved styles, product dialogs and a preview shopping bag. Browser storage retains the saved styles and bag; browsing also works when storage is unavailable.

Before commercial launch, replace sample catalog data and photography with approved products, connect inventory and checkout, and provide store policies. This change does not deploy the site.
